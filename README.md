# Brave

**Brave** is a fast-paced 2D survival/puzzle game built with Unity. Players must navigate a hazardous environment filled with dynamic enemies and rotating obstacles to retrieve a key and reach the exit.


## 🎮 Gameplay Overview
In **Brave**, you control a red square in a world where everything else is out to stop you. Your objective is simple but challenging:
1.  **Avoid the Enemies:** Pink circles and certain blue squares will hunt you down.
2.  **Timing is Everything:** Navigate through moving blue squares that oscillate vertically and dodge a grey rectangular bar spinning in a circular motion.
3.  **The Objective:** Successfully grab the **Yellow Key** to unlock the path.
4.  **The Finish Line:** Reach the **Green Square** to complete the level.

## 🕹️ Features
* **Dynamic AI:** Pink circle enemies that actively follow the player's movements.
* **Obstacle Patterns:** Vertical oscillating blue squares and a rotating grey barrier that require precise timing.
* **Minimalist Aesthetic:** Clean, high-contrast 2D graphics for clear gameplay visibility.
* **Unity Powered:** Built using C# and Unity's 2D engine for smooth physics and controls.

## 🛠️ Controls
* **W / Up Arrow:** Move Up
* **A / Left Arrow:** Move Left
* **S / Down Arrow:** Move Down
* **D / Right Arrow:** Move Right

## 🚀 Getting Started
### Prerequisites
* Unity Hub
* Unity Editor (2021.x or later recommended)

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/Brave.git
    ```
2.  Open **Unity Hub**.
3.  Click **Add** and select the cloned folder.
4.  Open the project and hit the **Play** button to start the game!
